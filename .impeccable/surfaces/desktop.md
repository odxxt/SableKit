# Desktop surfaces

Mode: Operate. Scope: native tray, action library/configuration, compact network checks.

## Direction contract
THESIS: Reach a useful action in one click, then return to work. Configuration belongs in a deliberate larger workspace.

OWN-WORLD: Smoked charcoal, white action labels, quiet gray metadata, thin neutral outlines, 12–16 DIP control radii, native Segoe UI, consistently drawn line icons. Real system acrylic when supported; an opaque charcoal fallback maintains readability.

STORY: Open, find, run, see the actual result. Pin when staying; edit without making the tray into a settings form.

FIRST VIEWPORT: 336 x 404 DIP panel with a 32-DIP search/pin header, conditional suggestion, pinned list/grid, secondary tool strip and profile footer. Main window caps at 920 x 640 DIP and 90%/88% of monitor work-area width/height, with a visible 40-DIP caption row. Header controls match SableLatch Windows glyphs and borderless active-fill behavior; Pinned is explicit in the title.

FORM: User-pinned SableLatch/Raycast-adjacent operation surface. Context launcher and concept-seed were attempted but their engine download failed; no seed key exists. Explicit user direction and direct-code choice govern this build, not an invented roll. Signature feedback is a stable-sized centered checkmark and Copied only after successful clipboard write.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

No shipping rasters planned. Built-in vector icons are original geometry; header/caption glyphs use Windows Segoe MDL2 Assets. Adapted SableLatch header styling retains its MIT notice. No animation runs while hidden. Review must distinguish captured WPF rendering from compositor/native-interaction validation.
